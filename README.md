# Stereoo Gemini Live: отдельный эксперимент

Эта ветка предназначена **только для проверки прямого speech-to-speech Realtime на Motorola**.
Она не заменяет установленное Stereoo AI 21.x, не меняет логику кнопок BV200,
не запускает микрофон в фоне и не содержит рабочего обхода географических ограничений.

## Возможности
- Прямая WebSocket-сессия Gemini `gemini-3.8-live` (не TTS и не STT + TTS).
- Захват звука Android AudioRecord в PCM 16kHz, передача каждые 100 мс.
- Приём PCM 24kHz и воспроизведение Android AudioTrack.
- Отправка JPEG из галереи внутрь той же сессии.
- Перебивание по событиям `interrupted`, отображение транскрипций.

## Запуск
1. **Сначала** убедиться, что для аккаунта доступен Google AI Studio / Gemini API
   в [поддерживаемой стране](https://ai.google.dev/gemini-api/docs/available-regions).
   Россия не указана в перечне доступных регионов. VPN не означает, что использование разрешено.
2. Получить собственный ключ Google AI Studio **только если это разрешено в вашей стране**.
3. Собрать debug APK из ветки `pilot/gemini-live-20261111`, установить рядом
   с основным приложением (applicationId другой).
4. Открыть приложение на телефоне, вставить ключ (не в GitHub!), разрешить микрофон.
5. Нажать «Начать Live», произнести несколько фраз, попробовать перебить голос.
6. Нажать «Отправить фото» и выбрать снимок. Он уйдет в текущую Live-сессию.

Ключ API вводится только для текущего процесса. Для массового использования нужны
короткоживущие [ephemeral tokens](https://ai.google.dev/gemini-api/docs/live-api/ephemeral-tokens),
выдаваемые сервером. Текущая схема намеренно ограничена локальным тестированием.

## Ограничения
- Нет кнопок очков, интеграции HeyCyan, фонового микрофона и заблокированного экрана.
- Bluetooth-маршрутизация звука зависит от Android: сначала проверяется телефон.
- Не проверено на физическом устройстве и в реальной Live-сессии.
- Важно проверить действующие ограничения Free tier в своем кабинете AI Studio.
- Если Google отклоняет запрос из-за региона, это не ошибка кода.

Официальная документация: https://ai.google.dev/gemini-api/docs/live-api/get-started-websocket
